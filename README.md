# Technical Writing Portfolio

Welcome to my documentation portfolio, This repository showcases my ability to create clear, user-friendly, and well-structured technical content. 

As a technical writer, I specialize in translating complex technical concepts into accessible guides for end-users and developers alike.

##  Sample Projects

Here are a few samples of my recent documentation work:

* [Amazon User Guide: Create an Account](https://github.com/jagat0034/User-Manuals/blob/main/Amazon%20User%20Guide_%20Creating%20an%20Account.md): A step-by-step consumer guide demonstrating task-based formatting, sequential instructions, and the effective use of UI callouts and warnings.
* [Withdraw cash from an ATM](https://github.com/jagat0034/User-Manuals/blob/main/Withdraw%20cash%20from%20an%20ATM.pdf): A step-by-step PDF consumer guide built in [Confluence](https://parthasarathy14320-1776776976145.atlassian.net/wiki/spaces/~712020a6ba54d3857847eeb22198cbbe4e3b58/pages/2064385/Withdrawing+cash+from+an+ATM+A+user+guide) which features a custom draw.io flowchart and clear safety warnings, all written to Microsoft Manual of Style (MSTP) standards.
* Introduction to APIs: A conceptual guide covering API fundamentals including architecture types, REST methods, CRUD operations, JSON, and HTTP status codes — written to help technical writers understand APIs before documenting them.
* [Testing REST API Using Postman](https://github.com/jagat0034/User-Manuals/blob/main/Testing%20REST%20API%20Using%20Postman.pdf): This document demonstrates practical knowledge of API testing and technical documentation using Postman and Supabase. All content is written in accordance with the Microsoft Manual of Style for Technical Publications (MSTP), covering authentication setup and full CRUD operations against a live REST endpoint. All student data used in this document is fictitious and for demonstration purposes only.
* [Amazon Shopping App Release Notes — v12.3.0](https://github.com/jagat0034/User-Manuals/blob/main/Amazon%20Shopping%20App%20Release%20Notes%2C%20Version%2012.3.0.pdf): A software release note authored in [Confluence](https://parthasarathy14320-1776776976145.atlassian.net/wiki/spaces/~712020a6ba54d3857847eeb22198cbbe4e3b58/pages/13631489/Amazon+Shopping+App+Release+Notes+Version+12.3.0), documenting a new feature, improvements, and known issues for a consumer mobile app, written to MSTP standards with structured UI path formatting and clear technical language.
